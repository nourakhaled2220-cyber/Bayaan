# بيان | Bayan

تطبيق ويب يربط يوم المسلم بدينه: **اسأل بيّان** (إجابات بمصدر)، و**تأمل** (تأمل خاص بصورتك)، و**وِردك** (المصحف الكامل مع ستريك)، و**الأصدقاء والتصنيف الشهري**.

مشروع لهاكاثون «تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي».

## الميزات
- **اسأل بيّان:** شات مرتبط بقاعدة معرفة إسلامية، يعرض المصدر (Botpress).
- **تأمل:** تصوّر أي شيء أمامك فيحلل الذكاء الاصطناعي الصورة ويكتب تأملًا مرتبطًا بها، بضوابط شرعية (يذكّر ولا يفتي). ستريك للأيام المتتالية.
- **وِردك:** المصحف كاملًا (٦٠٤ صفحة) من مصدر قرآني (alquran.cloud)، وهدف يومي، وعلامة إتمام، وستريك خاص بالورد.
- **الأصدقاء والتصنيف:** إضافة صديق بكود، وقصص يومية، وتصنيف شهري على الأصدقاء والمنطقة والدولة والعالم (الاسم الأول فقط، والمشاركة اختيارية).

## التقنيات
- واجهة ويب بملف واحد (`index.html`): HTML / CSS / JavaScript.
- Botpress: المحادثة.
- Google Gemini: تحليل الصور.
- Firebase (Authentication + Firestore): الحسابات والأصدقاء والتصنيف.
- alquran.cloud: نص القرآن.
- Netlify: الاستضافة.

## التشغيل
1. افتح `index.html` من أي استضافة ثابتة (مثل Netlify Drop) أو محليًا.
2. للتحليل الحقيقي للصور، ضع مفتاح Google AI Studio في المتغير `GEMINI_KEY` داخل `index.html`.
   **لا ترفع المفتاح إلى GitHub.**
3. الحسابات والتصنيف تحتاج مشروع Firebase وقواعد Firestore تشمل المجموعات `users` و`codes` و`board`.

## تنبيهات
- نسخة أولية للتجربة. التأملات المولَّدة بالذكاء الاصطناعي لم تُراجَع شرعيًا بعد.
- لغات الواجهة: العربية والإنجليزية مكتملتان، وبقية اللغات تعتمد على الإنجليزية.
